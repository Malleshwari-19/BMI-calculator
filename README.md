# BMI Calculator Using Java

##  About the Project

The BMI Calculator is a simple console-based Java application that calculates the Body Mass Index (BMI) of a person using their weight and height.

The program accepts weight in kilograms and height in meters from the user and calculates BMI using a mathematical formula.

This project was developed as part of my Java programming practice to understand user input, variables and mathematical operations.

##  Features

- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates Body Mass Index (BMI).
- Displays the calculated BMI result.
- Uses console-based input and output.

##  BMI Formula

BMI is calculated using the following formula:

**BMI = Weight (kg) / Height (m)²**

##  How to Run

**Prerequisite:** Java Development Kit (JDK) installed.

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in your Java IDE.

3. Compile the Java file:

   ```bash
   javac BMICalculator.java
   ```

4. Run the program:

   ```bash
   java BMICalculator
   ```
